# com he fet el meu segon cervell

La guia pas a pas de com capturo des del mòbil i la IA ho endreça cada nit a l’ordinador. Es publica a GitHub Pages: **ivetanoro.github.io/segon-cervell**.

- `index.html` — la web. Les animacions (el mòbil, el tauler i la tasca de nit) estan fetes en codi dins la pàgina.
- `video/` — el mapa d’inspiració, gravat a l’ordinador i al mòbil.
- `text-base.txt` — el text per enganxar a la IA (el mateix que copia el botó).
- `com-he-fet-el-meu-segon-cervell.pdf` — la guia en PDF, per a A4.
- `fonts/` — les lletres de la marca.

La web es fa a l’Estudi (`projectes/segon-cervell/guia/web`, amb `python3 fes.py`) i aquí només es copia el resultat.
